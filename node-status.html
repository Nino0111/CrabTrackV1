🖥 RASPBERRY PI QUICK CHECKS

Run these in the Raspberry Pi terminal. The MQTT listener command requires mosquitto-clients to be installed.

cd ~/crab-monitor
curl -s http://127.0.0.1:3000/api/status
curl -s http://127.0.0.1:3000/api/data
curl -s http://127.0.0.1:3000/api/nodes
sudo systemctl status mosquitto --no-pager

Note: “Offline” means no recent data reached the Pi; it does not prove the ESP32 itself has no power. Check the serial monitor, Wi-Fi, MQTT broker address/topic, and Pi logs to isolate the cause.

DAILY PUMP OFF SCHEDULE

Uses Philippine time (UTC+8). At the selected time, the pump turns OFF for the chosen duration, then automatically resumes ON. Manual ON/OFF cancels the current timed OFF period.

Safety: Pump starts OFF after reboot. The schedule uses ESP32 network time. This pump firmware does not add a pump/solenoid interlock; do not run pump and drain valves together unless your plumbing design permits it.

DAILY DRAIN SCHEDULE

Philippine time (UTC+8). At the selected time S1 and S2 open. Manual ON commands time out after 120 seconds; the scheduled duration is separately configurable.

Safety: S3 and S4 are mutually exclusive. Each manual valve activation shuts off after 120 seconds. Automatic salinity dosing is disabled. This firmware does not provide a pump interlock.

SCALES — TARE / CALIBRATE (no Arduino IDE needed)

Pick a compartment. Requests go online through Firebase - no Raspberry Pi needed (the Pi is only a local backup). The board picks the request up within a few seconds, does it, and reports back below. Requests the board doesn't pick up within 2 minutes are cancelled, so a late tare can never zero a loaded scale.

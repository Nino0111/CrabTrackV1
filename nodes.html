A node that posts data with an unknown ID registers itself automatically, so this form is really just for naming it ahead of time.

🍤 FEEDING SCHEDULE

Set the times crabs should be fed. The Pi checks every 5 minutes and raises an alert (and sends a message, if configured) when a feeding time passes without a FED entry being logged. This runs on the Pi itself, so it works with no browser and no phone open. Grace is how long after the due time before a gentle reminder turns urgent.
